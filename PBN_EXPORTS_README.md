# Paint by Number — Recolor Export Add-on

Versión visible actual: **Recolor v2.4**

## Incluye en esta versión
- Mantiene todos los fixes anteriores.
- El QR conserva su contenedor premium, pero ahora queda **centrado entre los textos** “ESCANEA QR” y “PARA HACERLE ZOOM”, alineado respecto al eje visual del template.
- La imagen principal sigue sin marco/contendor visual.
- Formato de impresión: **Oficio vertical**.
- En la plantilla PDF y en el JPG de marcadores, el título muestra la cantidad total de colores: `Marcadores incluidos (N colores)`.
- SVG defaults: `SVG size multiplier = 7` y `Label font color = #C4C4C4`.

## Al guardar el PDF
- Elegir **Guardar como PDF**
- Papel: **Oficio**
- Orientación: **Vertical**
- Escala: **100%**
- Márgenes: **Ninguno**
- Desactivar **Encabezados y pies de página**
