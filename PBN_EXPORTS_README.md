# Paint by Number — Recolor Export Add-on

Versión visible actual: **Recolor v2.0**

## Incluye en esta versión
- Plantilla limpia aprobada visualmente.
- QR dentro de un contenedor dedicado, con autoescala y posición protegida para no tapar textos.
- Imagen principal dentro de un contenedor más robusto, con presentación más premium.
- Sección “Marcadores incluidos” sin borde ni fondo, con proporciones refinadas.
- Sombra sutil y ajustes visuales para un look un poco más premium.
- Colores bloqueables como NO DISPONIBLE y sugerencias que saltan automáticamente a la siguiente opción disponible.
- Botón QUICK APPLY SUGGESTIONS.
- Formato de impresión: **Oficio vertical**.

## Al guardar el PDF
- Elegir **Guardar como PDF**
- Papel: **Oficio**
- Orientación: **Vertical**
- Escala: **100%**
- Márgenes: **Ninguno**
- Desactivar **Encabezados y pies de página**


## Defaults SVG actualizados
- SVG size multiplier por defecto: `7`
- Label font color por defecto: `#C4C4C4`
