# Paint by Number — Recolor Export Add-on

Versión visible actual: **Recolor v2.1**

## Incluye en esta versión
- Todo lo de la versión premium anterior.
- Formato de impresión: **Oficio vertical**.
- SVG defaults actualizados: `SVG size multiplier = 7` y `Label font color = #C4C4C4`.
- En la plantilla PDF y en el JPG de marcadores, el título ahora muestra la cantidad total de colores: 
  - ejemplo: `Marcadores incluidos (24 colores)`

## Al guardar el PDF
- Elegir **Guardar como PDF**
- Papel: **Oficio**
- Orientación: **Vertical**
- Escala: **100%**
- Márgenes: **Ninguno**
- Desactivar **Encabezados y pies de página**
