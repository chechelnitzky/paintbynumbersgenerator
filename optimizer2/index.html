Cómo leer el resultado

No reemplaza un conflicto de forma aislada. Dentro de cada estuche toma todos los colores a la vez y hace una asignación global 1:1. Por eso puede resolver cadenas como 71 → 72, mientras el diseño que tenía 72 → 74, si esa combinación produce menor costo visual total.

95 · libre y conservado 32 · conflicto, se lo quedó 53 → 179 · conflicto, cedió 71 → 72 · movimiento estratégico

Rojo no significa error final: significa que ese marcador estaba repetido originalmente, pero este diseño terminó conservándolo. Morado significa que el color no estaba en conflicto originalmente, pero se movió para mejorar la solución global.
